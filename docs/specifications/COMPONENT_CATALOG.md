# Component catalog

The openui backend's component table, generated by hand from
`src/backends/openui/signatures.ts`. When the table changes, this file changes.

**8 of 48.** The remainder are catalogued in
`upstream/open-intelligent-ui/src/lib/library.ts` and arrive in stage 4, each
with its own security review where it widens a surface.

| Component | Group | Args | Notes |
| --- | --- | --- | --- |
| `Col` | Layout | `children, gap?` | Vertical stack |
| `Row` | Layout | `children, gap?, justify?` | `justify`: start \| center \| end \| between |
| `Card` | Layout | `children, variant?, padding?, gap?` | `variant`: soft \| outlined \| elevated |
| `Title` | Text | `text, size?, color?` | `size`: sm…3xl |
| `Text` | Text | `text, size?, color?, weight?` | `weight`: normal \| medium \| semibold |
| `Caption` | Text | `text, color?` | Secondary text |
| `Button` | Inputs | `label, action?, variant?, size?, icon?, disabled?` | `variant`: primary \| secondary \| ghost \| outline \| danger |
| `Slider` | Inputs | `value, min, max, step?, label?, unit?` | Binds a `$variable` |

## Not yet available

`Box`, `Grid`, `Carousel`, `Popover`, `Divider`, `Spacer`, `Label`, `Badge`,
`Link`, `List`, `ListItem`, `Quote`, `Code`, `IconButton`, `Pressable`,
`Input`, `TextArea`, `Select`, `SegmentedControl`, `Checkbox`, `RadioGroup`,
`DatePicker`, `Timer`, `Form`, `Image`, `Icon`, `Table`, `Chart`,
`Flashcard`, `Celebration`, `Svg` + its 9 primitives.

A model that writes one of these gets `unknown component` with a line number —
never a silently empty card.
