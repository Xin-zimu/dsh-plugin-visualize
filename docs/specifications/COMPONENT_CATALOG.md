# Component catalog

The openui backend's component table, generated by hand from
`src/backends/openui/signatures.ts`. When the table changes, this file changes.

**30 of 48 render.** The language *understands* all 48 — `signatures.ts` lists
every one, so the validator accepts them — but the renderer (`COMPONENTS` in
`src/client/OpenUICard.tsx`) draws only the thirty below.

That count is **measured, not remembered**: `tests/openui-inventory.spec.tsx`
imports both tables (the language's, and the renderer's now-exported
`RENDERED_COMPONENTS`) and prints the split. An earlier probe mirrored the
renderer's table as a hand-written literal and kept answering "8 of 48" long
after the renderers existed — a copy of an answer is not a measurement.

## The gap a model can fall into

An unrendered component is **accepted by validation and drawn as nothing**. This
is measured, not inferred: `evidence/phase-3/unrendered-component-check.txt`.

| Program | `validate` errors | What the reader sees |
| --- | --- | --- |
| `root = Col([Grid([])])` | none | a drawn, empty grid |
| `root = Col([Table([])])` | none | a "Table is not drawn by this build" notice |
| `root = Col([Chart([])])` | none | a "Chart is not drawn by this build" notice |
| `root = Col([Map([])])` | `VZO002 unknown component "Map"` | the call is rejected |

The safety net covers names the **language** does not know (`Map` is
open-intelligent-ui's, not ours). For names the language declares but the
renderer does not draw, 4A-1 added an explicit notice rather than silence — see
below.

That is a known, recorded limitation rather than a design position: the fix is to
finish the renderers (4A), not to reject names the dialect declares. Rejecting
them would make the language disagree with its own signature table, which is the
drift ADR-002 exists to prevent.

### A declared name with no renderer now says so

Before 4A-1, `drawValue` returned `null` for a declared-but-undrawn component, so
a legal program drew a silently empty card — indistinguishable from a card that
was *meant* to be empty. The two are now different by construction:

| Case | What is drawn |
| --- | --- |
| Legal empty container, e.g. `Grid([])` | the container itself, e.g. `display:grid` with zero children |
| Declared component with no renderer, e.g. `Table([])` | a muted notice: `Table is not drawn by this build`, carrying `data-openui-unrendered="Table"` |
| Name the language does not declare, e.g. `Map` | nothing; the host rejects the program at validation (`VZO002`) |

The notice is not a substitute for the renderer — it is a diagnostic that stops a
renderer gap from looking like an intentional blank.

| Component | Group | Args | Notes |
| --- | --- | --- | --- |
| `Col` | Layout | `children, gap?` | Vertical stack |
| `Row` | Layout | `children, gap?, justify?` | `justify`: start \| center \| end \| between |
| `Card` | Layout | `children, variant?, padding?, gap?` | `variant`: soft \| outlined \| elevated |
| `Box` | Layout | `children, direction?, gap?, padding?, background?, radius?, border?, width?, height?, flex?, align?, justify?, wrap?` | Flex container, column by default. A semantic `background` paints a 14% tint of that series; `border`: true \| number \| `l1` \| `l2` \| CSS shorthand; `radius` clips content only when set |
| `Grid` | Layout | `children, columns?, minChildWidth?, gap?` | 2 equal columns by default. `columns` may be a count or a CSS track list; `minChildWidth` uses `auto-fit` with a `min(100%, …)` floor, so tracks drop as the card narrows |
| `Divider` | Layout | — | 1px rule in the host border colour |
| `Spacer` | Layout | — | `flex: 1 1 0` with a 4px floor; elastic in a Row |
| `Title` | Text | `text, size?, color?` | `size`: sm…3xl |
| `Text` | Text | `text, size?, color?, weight?` | `weight`: normal \| medium \| semibold |
| `Caption` | Text | `text, color?` | Secondary text |
| `Label` | Text | `text` | Field or group label: 12px, medium weight |
| `Badge` | Text | `text, color?` | Status pill. `color`: info \| success \| warning \| danger \| purple \| pink. Colour rides on a 6px dot plus a 16% tint; the text stays foreground, because tinted text at 11px fails AA |
| `Link` | Text | `text, url` | **ADR-008.** Renders `<a target="_blank" rel="noreferrer noopener">` **only** for an absolute `http:`/`https:` URL, parsed with `new URL`. Everything else (`javascript:`, `data:`, `file:`, `blob:`, `mailto:`, `tel:`, `//host/x`, relative paths, fragments) degrades to plain text with its label still visible |
| `List` | Text | `items, marker?, timeline?` | `marker`: bullet \| number \| dash \| check \| none. An entry may be a string, a `ListItem`, or a drawn node. Capped at 200 rows, and a truncated list says so rather than ending silently |
| `ListItem` | Text | `title, description?, marker?, children?` | One list row. Nested in a `List` it supplies its own marker; drawn directly it is a single row |
| `Quote` | Text | `text, cite?` | `<blockquote>` with a 2px brand-colour side rule |
| `Code` | Text | `code, language?` | Monospace block with a language label and a copy button. The copy is best-effort and a refused permission never throws. Text is never interpreted as markup |
| `Button` | Inputs | `label, action?, variant?, size?, icon?, disabled?` | `variant`: primary \| secondary \| ghost \| outline \| danger. `action`: `@Set`, `@Reset`, `Action([...])` |
| `Slider` | Inputs | `value, min, max, step?, label?, unit?` | Binds a `$variable` |
| `IconButton` | Inputs | `icon, action?, label?, variant?` | Placeholder glyph until 4A-4 draws `Icon`: the name in a bordered square, visibly a placeholder rather than a blank button. Runs its action through `write.runAction`, the same channel `Button` uses |
| `Pressable` | Inputs | `children, action?, selected?, padding?, background?, radius?` | A clickable region: `role="button"`, `tabIndex=0`, Enter and Space both run the action. Without an action it is inert rather than focusable and dead |
| `Input` | Inputs | `value, label?, type?, placeholder?` | Binds `$state`. A `number` field writes a **number**, so `$n + 1` stays arithmetic instead of concatenating |
| `TextArea` | Inputs | `value, label?, placeholder?, rows?` | `rows` clamped to 1…24 so a program cannot push the card past the viewport |
| `Select` | Inputs | `value, options, label?, placeholder?` | Reads `options` from the raw argument list; writes the option's **original** value, so `{value: 1}` writes `1`, not `"1"` |
| `SegmentedControl` | Inputs | `value, options, block?` | Two to four short choices as one `radiogroup` |
| `Checkbox` | Inputs | `checked, label, lineThrough?` | Writes a boolean; `lineThrough` strikes the label when checked |
| `RadioGroup` | Inputs | `value, options, label?, variant?` | Cards add a description line; one `radiogroup` per group |
| `DatePicker` | Inputs | `value, label?, min?, max?` | Writes `YYYY-MM-DD` |
| `Timer` | Inputs | `seconds, label?` | The only control that writes on a clock: one interval writes the bound seconds every second, so a sibling `Text` counts down with it and a reload resumes where it stopped. `role="timer"` and `role="progressbar"` |
| `Form` | Inputs | `children` | Groups fields. Never submits — a submit would navigate the host pane away from the conversation |

## Not yet available — validated but not drawn

These are declared by the language and have no renderer, so a program using one
shows a "not drawn by this build" notice. The batch column is the stage-4A plan
(`STAGE.md`).

| Batch | Components |
| --- | --- |
| 4A-4 | `Table`, `Chart`, `Icon`, `Image` |
| 4A-5 | `Svg`, `G`, `Circle`, `Ellipse`, `Rect`, `Line`, `Path`, `Polyline`, `Polygon`, `SvgText`, `Flashcard`, `Celebration`, `Carousel`, `Popover` |

The authoritative list is measured, not typed: `tests/openui-inventory.spec.tsx`.
If this table and that output disagree, the output is right.
