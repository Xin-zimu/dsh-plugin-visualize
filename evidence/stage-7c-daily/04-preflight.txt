  the profile or the desktop CLI is missing.
- `-Rollback` restores the newest backup, runs the same desktop-CLI install, and
  verifies the upstream plugin is installed again.
- Manual fallback: copy the two files back from the backup directory, then
  `dsh plugin --profile desktop install`.
