# N5 — `src/client/openui-actions.ts` docstring correction, and its measured impact

Owner requirement: "修正后重新检查产物哈希、构建确定性及相关测试。不得默认注释修改不会影响 bundle。"

So the claim that a comment cannot reach the bundle was MEASURED, not assumed.

## 1. What was wrong

Lines 10-12 said:

    Scope (P3-07): `@Set`, `@Reset` and `Action([...])` — the three that only
    touch local `$state`. `@OpenUrl`, `@CopyToClipboard` and `@ToAssistant` are
    recognised and refused, so they are inert rather than silently mis-handled.

`@CopyToClipboard` SHIPPED in stage 4B (ADR-013) and is in SUPPORTED_STEPS. It is
not refused. The sentence was true at P3-07 and stale since.

## 2. The change

    Scope: `@Set`, `@Reset` and `Action([...])` touch local `$state`; the stage-4B
    batch added `@CopyToClipboard`, which produces no patch and is refused when
    nested (see {@link ActionOutcome.clipboard}). `@OpenUrl` and `@ToAssistant` are
    recognised and refused, so a Button carrying one is inert rather than silently
    mis-handled — and it says which name it declined when pressed.

The diff is entirely inside the module docstring. No code, no export, no behaviour.

## 4. Why the hash is unchanged — two checks, not a hopeful assumption

(a) The text is NOT in the bundle at all:
      new docstring found in lib/client.js : False
      old docstring found in lib/client.js : False
    tsdown strips comments; neither the old nor the new wording survives.

(b) CONTROL — a real code change DOES move the hash:
      mutated  MAX_CLIPBOARD_TEXT = 32 * 1024  ->  33 * 1024
      rebuilt  client.js SHA256 = AAE2F13D782C217CD79D93B074C9BA922D87F97610162E682BC51613F8376BB9
      CHANGED: True
      then restored the file and rebuilt:
      restored client.js SHA256 = E1BF4A82B3C808899BA868009CF9DEAD15F941E6A3614040DB1E73C031456CEB
      BACK TO BASE: True

Without (b), (a) would be a guess: an unchanged hash proves nothing if the build
were stale or if the toolchain were not reading the file. (b) proves the build is
live and that only a CODE change moves the hash.
